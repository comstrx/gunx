# History

## Contract

Own historical writing conventions. Records preserve observations, including possible mistakes; they are not approved engineering knowledge.
Only an explicit owner decision can promote a recorded finding into its responsible skill.

## Structure

Report contains authored lessons; track preserves completed IPC records.
A live IPC report.md is a message, not a lessons report.
Each record belongs to its exact responsibility scope, then a daily directory.

## Rules

### Daily organization

- Append `YYYY-MM-DD/` after the final scope directory, never before the scope or between its levels.
- Use the owner's working-date timezone; absent one, use UTC consistently. State the date basis when it matters across zones.
- Use the day the report is published or the message is archived. Keep original event dates inside the record.
- Number records within that scope and day. Each writing guide owns its filename form.
- Create an unused destination without replacing an existing file; concurrent writers must not overwrite one another.
- Finding available names may inspect directory entries, never historical file contents. A naming collision selects another unused name.
- Do not reorganize existing history or revise old evidence as incidental maintenance.

## Proof

Scope, date and filename identify the record. Historical mistakes cannot silently become active rules.

## Sources

Owner history organization and knowledge-promotion decisions.
