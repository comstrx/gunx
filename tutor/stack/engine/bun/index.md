# engine/bun

One workspace of 37 member packages under `src/<member>/`, fronted by one facade package, `engine`, that exports one subpath per member, shared word for word by every `web`, `mobile` and `desktop` of every product.

## Layout

```
engine/bun/
├── src/<member>/   package engine-<member>, private, no version: package.json (its members and libraries by name: workspace:* and catalog:, exports "." → src/index.ts) and src/ (index.ts, the public surface, + flat files)
├── src/world/      the one member that also carries data/ (countries, currencies, languages, regions, emojis, emoji-groups, fonts as json) and asset/ (flag/*.svg, font/*.woff2, emoji/*.webp and LICENSE.txt; a test proves every file the data names exists and nothing unnamed sits there); `tool.assets()` names that folder for a surface's copy step (the engine's own home unless a path is given, as `tool.members()`)
├── src/engine/     the facade: package.json (depends on every member with workspace:*, exports . → src/index.ts and ./<member> → src/<member>.ts), src/index.ts (`export * as <member>` per member) and src/<member>.ts (one line re-exporting the member)
├── tests/          flat <member>.test.ts (+ <member>.<topic>.test.ts when one grows), laws.test.ts, audit.test.ts (licenses), api.test.ts over api.json (every member's recorded exports)
├── benches/        flat <member>.bench.ts, one per member, on mitata
├── fuzz/           flat <member>.test.ts on fast-check, run by `bun run fuzz`
├── .bun/           the link registry: `engine`, `react`, `react-dom`, registered by `bun run link`
└── package.json  bun.lock  node_modules/  bunfig.toml  biome.json  tsconfig.json
```

One workspace, one artifact: `workspaces` and the `catalog` (every library's one version) live in the root `package.json`; a member's manifest carries no number; `node_modules/` and `bun.lock` exist once, at the root (`linker = "hoisted"`); a member that imports what it did not declare is refused by Biome (`noUndeclaredDependencies`) and by the shape law.

## Facade and link

- The facade's `exports` maps `./<member>` → the member's index, and `.` → `src/index.ts`, the whole engine as namespaces; nothing else. Every import is `import * as <member> from "engine/<member>"` and every call reads `<member>.verb()`; inside the engine a member reaches a sibling as `engine-<member>`; a member's index exports only what something outside uses; a local never shadows a member name.
- Every external dependency is pinned once in the root `catalog`; a member asks for it with `catalog:` and for a sibling with `workspace:*`; React is a peer of the members and a catalog pin of the workspace.
- **One React:** the catalog pins `react` and `react-dom` at the version the React Native renderer embeds and Expo bundles (19.3.0 today). `bun run link` registers `engine`, `react` and `react-dom` in `.bun` through `BUN_INSTALL_GLOBAL_DIR` (Bun ignores `install.globalDir` for links), and every surface depends on `link:engine`, `link:react`, `link:react-dom`, so one React instance renders every engine hook. A surface's `deps` script installs with the same `BUN_INSTALL_GLOBAL_DIR`.
- Next compiles the facade and every member through `transpilePackages` with `turbopack.root` and `outputFileTracingRoot` at the nearest folder holding the surface and the installed engine (found through `node_modules/engine`, never through the tree's layout); Metro watches the engine's real path, follows its symlinks and resolves host packages from the surface. The day the engine leaves, the surfaces swap `link:` for a release reference and nothing else changes.

## Laws

- **Runtime** (Biome): `Bun process Buffer require` and `bun bun:* node:*` imports are refused in `src/` except `tool` and `test` (build and test time). Nothing in the engine renders: no element, no HTML, no brand, no color value, no copy; a surface owns its `elements/`.
- **Shape** (test): members form a DAG and declare exactly the siblings they import; the facade has one namespace and one door file per member; every manifest is private, named `engine-<dir>`, siblings by `workspace:*`, libraries by `catalog:`, a description of at most 80 characters.
- **Terminal** (test): `api`, `spec` and `tool` are the only members that know the spec architecture; nothing imports them and they never import each other. Every other member is general to any project.
- **Ports** (test): a platform difference is a port, never a runtime check inside shared logic. A member that needs the host creates its port through `adapter` (`adapter.port`, `adapter.family`) and the surface binds its adapter at boot with one verb: `net.fetcher.use`, `socket.factory.use`, `history.port.use`, `device.port.use`, `world.appearance.use`, `fs.disk.use`, `cache.use(kind, driver)`. A port carries a fallback where the web host answers (fetch, WebSocket, history, localStorage) and refuses with `<port>.unbound` where it does not (the disk); the port's own file declares the fallback (a module whose only work is a binding at import is dropped by a bundler that trusts `sideEffects: false`); `port.with(adapter, work)` scopes a binding to one call, so a test never leaks one.
- **Host-free** (test): `adapter` is the only member that reads the host. `adapter.host()` is the typed host (`adapter.Host`: navigator, document, location, history, the storages, fetch, WebSocket, Notification, matchMedia, crypto, the runtime marks), `adapter.web(name, make, otherwise?)` is a port's fallback: it answers from the host, else `otherwise()`, else refuses `unavailable` under `name`. In every other member the names `globalThis window document navigator location history localStorage sessionStorage fetch WebSocket Notification matchMedia ResizeObserver process Bun Deno crypto` never appear as free identifiers (a namespace import such as `crypto` from `engine-crypto` is the member's own name); `test` and `tool` are tooling and may read the host. `tsconfig` has `lib: ["ES2024"]`: no DOM type is ambient; what a member needs of the host it takes from `adapter.Host`.
- **Verbs** (test): a constructor is `create` (a runtime instance), `define` (declarative data) or `open` (a handle on something that already exists); `use` binds a port or a family and nothing else; no export is named `make* build* new* init* setup* construct*` or `use<X>`, and none carries a host name (`window document navigator fetch …`). A member may export a file of its own as a namespace (`value.money`, `value.decimal`): recorded and proven by its dotted name, judged by its last word.
- **Proof** (test + coverage): every runtime export recorded in `tests/api.json` is named by a test; `bun run test` = `bun test ./tests --coverage` (text and lcov reporters in `bunfig.toml`) then `tests/coverage.ts`, which reads `coverage/lcov.info` and holds the totals at lines ≥ 95% and functions ≥ 90% and every file above the floors of 75% lines and 50% functions (Bun's own `coverageThreshold` is per file and unusable for a total); every parser has a fuzz target under `fuzz/`.
- **Size** (test): `tests/size.json` records every member's minified browser closure (`Bun.build` of the member's index with splitting, the entry output only, React external; `test` and `tool` are `null`, they never ship); a closure that grows past its record fails until `bun run record` renews it on purpose. A namespace closure counts every export; a surface pays only for what it imports, so the hello surfaces' own bundles are the second measure (`settings.budget`).
- **Record:** `bun run record` (`tests/record.ts`) rewrites `tests/api.json` and `tests/size.json` and prints `tool.apiDiff` against HEAD (`none`, `minor` for additions, `major` for removals) with every closure that moved; the CHANGELOG bullet of a change names that class.
- **Door** (test): a library enters through one file of one member (`validate/zod.ts` for `zod/mini`, `store/zustand.ts`, `store/bind.ts` for React, `test/index.ts` for mitata) and is re-exported by name, never as a namespace; `virtual` is pure windowing arithmetic, a React binding over it belongs to a surface.
- **Purity** (test): no comments, no `console` outside `log`, no `eval`, no default export in a member.
- **Nameless** (test): no file that leaves with the engine names a product or the tree it grew in; fixtures speak a placeholder brand.
- **Ownership:** a member reaches a lower domain through that member's verbs, never inline (`json.parse` not `JSON.parse`, `list.compact` not `.filter(Boolean)`).
- **Cache:** `cache` is the one home of what a surface keeps between calls: memory maps (`lru expiring swr remember dedupe tagged limiter`), cookies (`parseCookies serializeCookie documentCookies headerCookies signCookie unsignCookie`), one storage family (`memory local session` built in, a native driver registered by `cache.use("local", driver)`), boxes (`cache.open({ kind, prefix, secret, sign, ttl })`: json values, sealed and signed on demand, expiring, counted, watched across tabs) and typed stores. `store` persists through a box; `queue` keeps its jobs in a storage.
- **Device:** `device` is the one package for every ask of the host: facts (`info`, `watch` for online, scheme, motion, visibility, focus, size, network, language), permissions (`state ask require`), notifications and push tokens, location (`position follow`), clipboard, share, haptics, `open`, `pick`, `media`, `keys` with `hotkey("mod+k")`, battery. `device.create(adapter)` fills every missing capability with an honest `unsupported`, `can()` names what the adapter has; the web adapter lives in the member, a native adapter in the surface's `src/native`. `geo` locates over it (`geo.locate follow near`), never the reverse.
- **Spec:** the schema is data. `spec.surface/screen/block/feature` build it (a surface names its `platform` and the `world` catalogs it needs; a screen may declare a `flow` of steps; a feature may declare a `form` of rule strings); `spec.read/write/data/signal` bind ports (a `read` may carry a `list` of `sort filter page limit search` and a `live` topic); `spec.param/query/form/user/setting/fromSignal/fromEvent/text` reference the context (`text` is a message key); `spec.when("form.type=digital & !signals.on & can:orders.write")` parses a condition (`can:` checks the user's abilities through `auth`); `spec.set/clear/show/hide/enable/disable/emit/call/queued/refresh/navigate/branch/step/confirm/check` are effects (`step` walks the flow, `confirm` asks before it acts, `check` validates the feature's form into `signals.errors`, `queued` calls through the queue when the device is offline); `watch` maps a context path to effects, `on` names the hooks (`load leave submit success failure change`), `trigger` answers a bus topic. `spec.compile(surface, { blocks, features, catalogue, topics, texts, grants, maxDepth })` validates every block's props, every feature's settings against its manifest, every port against the catalogue (kind, input, fields, listing fields), every path against its namespace (`params query signals form user device settings locale event flow`), every text key against `texts`, every `access` and `can:` against `grants`, every step, form rule, target id, action, navigation path and consumed topic, and refuses a watch cycle; an issue names its path, rule and message and, where a name was mistyped, the `near`est valid name and the smallest `fix`; `spec.explain(compiled, screen)` is one page of the compiled truth. The compiler runs at build: `spec.serialize` writes the compiled role to json and `spec.revive` reads it back in the browser, so no compiler ships. What the builders make is branded (`spec.built`, `spec.isBuilt`) and trusted; the compiler validates only raw input (a whole raw surface at the gate, a raw screen, feature or block inside a built one as a `shape` issue), which is why a built surface compiles in microseconds per screen. `spec.runtime(compiled, { bus, navigate, handlers, translate, confirm, queue, rulebook })` mounts a screen (a role with a form hands `validate.rulebook` in and is refused with `spec.rulebook` without it; a role without a form never ships the dialect): context in a signal, watches, triggers and live bindings wired on mount and unwired on unmount, hooks run in order, `act(feature, action)` calls a handler and runs `success`/`failure`, `visible(id)`/`enabled(id)`/`allowed(id)` answer the view, `flow()` the step, `errors(feature)` the form. `api` and `spec` never meet: the surface passes `api.catalogue(features)` to `compile`.
- **Api:** `api.house` is the global contract as data (header names, envelope paths, pagination paths, idempotent methods, retries, timeout) and `api.wire(overrides)` is a part's full override; `api.create({ baseUrl, wire, token, locale, currency, tenant, client })` is the one client over the envelope (typed endpoints, a GET cache with `fresh: true`, typed faults, one request id per call); `api.live(realtime)` is the realtime contract over `socket` (channels and events as templates, `applyPatch` for rows); `api.fakes(features, { seed })` answers every endpoint from its schemas; `api.stub(routes, wire)` records calls; `api.address(url, { release, insecure })` refuses a lab address in a release. Edges and stubs speak the same envelope through `api.answer/refuse/paged`; `api.transportIssues(features)` lints a contract set (a route taken twice, a cached or listed write) and `api.openapi(features, info)` writes OpenAPI 3.1 from the contracts through `validate.toJSONSchema`.
- **World:** `world` is the one home of the world's facts and drawings. Facts: catalogs (`list.catalog`: get, has, keys, search over every name and code, pick, where) of countries (alpha-2, alpha-3, numeric, dialing keys and areas, regions, currencies, languages, names in English, Arabic and native; `byPhone`, `phone(text, fallback)` → E.164, `localOf`, `inRegion`, `spending`, `speaking`, `sorted(locale)`, `grouped(locale)`), dialing `keys`, currencies (`of`, `primaryOf`, `symbolOf`, `nameOf`, `digitsOf`, `minor`, `major`, `round`, `format`), languages (`directionOf`, `scriptOf`, `isRtl`, `ofCountry`, `withScript`), regions, emoji (browse, shortcodes, codes, glyphs, `isEmoji`, `emojisIn`, `stripEmoji`, `onlyEmoji`, image and flag paths), flags (emoji, code, file), fonts (families by script, `fontFaces`, `fontStack`, `fontPreload`, `fontFor`). The four heavy catalogs are lazy: `await world.load()` (or `load("countries", "emoji")`) fetches their JSON as split chunks; `countries currencies languages emoji` and `everyCountry() everyCurrency() everyLanguage() everyEmoji()` refuse with `world.unloaded` until then, `loaded(name)` tells; regions, groups, flags and fonts are static and small. Drawings: `icons(set, aliases)` (a registry that resolves names and aliases, mirrors in RTL, searches), `variables tokens → css custom properties`, `block`, `css({ base, dark, selector, prefix })` (light and dark as two art directions), `variants(recipe)` and `classes` and `states(flags) → data-*`, motion (`durations easings spring path toLinear ease transition reduced stagger tween`), colors (`color isColor rgb hsl oklch toHex toCss toHsl toOklch fromHsl fromOklch channels alpha mix blend lighten darken saturate rotate grayscale luminance contrast readable ensureReadable isDark onColor shades`: the CSS color grammar read into sRGB, OKLCH gamut-mapped by chroma at constant lightness and hue, `shades(brand)` the tints a surface derives its palette from), and the scheme machine `theme({ tokens: { light, dark }, box, key })`: a preference (`system light dark`) over the device scheme (the `appearance` port: `matchMedia` on the web, a native surface binds its own with `world.appearance.use`, and a theme follows a binding made after it), persisted through a cache box and hydrated back, `toggle`, `cycle`, `css()`, `variables(scheme)`, `apply(root)` writing `data-theme` and `color-scheme`; a `Readable` the surfaces bind with `store.bind`. The engine never holds a color or a glyph: tokens and icon sets come from the surface. `world.define({ locale, countries, currencies, languages, flags })` scopes the facts to a product. Data moves only with its source and license (CLDR, libphonenumber, Unicode Emoji, Figtree and Readex Pro under OFL); no row is ever invented.
- **Value:** `value` is the one reader of the unknown and the one home of typed values. Casts answer the type or `undefined` and never throw (`text integer number boolean date list listOf oneOf record scalar kind cast`: digits of any script, bidi marks and the Unicode minus read, digit grouping checked so `12,50` is refused and never read as 1250, blank is absent, a bounded length). Typed readers answer a branded canonical string (`email url phone slug key uuid ulid currency locale otp plainDate`; their `patterns` are the ones `validate` tests; a letter outside ASCII is refused before a case fold can turn it into one). `value.decimal` is exact decimal text (at most 40 fraction digits, seven rounding modes). `value.money` is `{ minor, currency }` in whole minor units on the ISO 4217 exponent: `of minor zero parse`, arithmetic, `percent tax gross net`, `allocate split total` that never lose a unit, `convert`, `format parts`, `toJson fromJson` (a wire whose `amount` and `minor` disagree is refused). No arithmetic passes through a float; `of` and the arithmetic throw a `RangeError` on what is not an amount, `parse` and `fromJson` answer `undefined`. `validate`, `world`, `translate`, `fake`, `parse` and `net` read through it.
- **Validate:** `validate` hands `zod/mini`'s own functions to its namespace through the one door, no layer between: makers `string number boolean date any unknown object strictObject looseObject array enum literal union record tuple lazy optional nullable nullish partial coerce instanceof custom uuid ulid`, checks composed by `.check(...)` (`minLength maxLength length regex trim toLowerCase toUpperCase startsWith endsWith includes int gt gte lt lte refine`), `pipe transform catch _default NEVER`, and the engine's fields (`text email url phone slug key password otp currency locale plainDate money ip file`); `check assert issuesOf` turn issues into the engine's rule codes (an unknown key is named by its full path, `address.extra`); `fields(schema)` reads the definitions themselves and `toJSONSchema` ships only where it is named; `rules("required|integer|between:1,5")` and `rulebook` speak the Laravel dialect. Types ride on mini's (`Schema<Out>`, `infer`, `output`, `input`), so inference never leaves zod. `compile(schema)` is zod's own compiler, opt-in for a hot path: it answers exactly as its source, hands the source back unchanged where the host refuses evaluation (a CSP without `unsafe-eval`) or the schema coerces or recurses, and throws under `{ strict: true }` instead; it is never the plan for a page served under a strict policy. Budgets held by `tests/size.test.ts`: a typical checked schema within 20 KB, the door adding nothing to zod, `compile` free until named and within 56 KB when it is.
- **Dependencies:** Bun owns them: `bun audit --audit-level=low`, exact pins, a minimum release age of three days (Biome's binaries, `@types/bun`, `fast-check`, `mitata` and `typescript` excluded by name), and the license allow-list of `tests/audit.test.ts` with named grants.

## Gate

`infra gate --part bun` (or `bun run gate`) = `bun install --frozen-lockfile && bun run link` · `bun run check` (tsc) · `bun run lint` (`biome ci .`) · `bun run test` (`bun test ./tests --coverage && bun tests/coverage.ts`) · `bun --smol test ./tests` (safety) · `bun run audit`; `bun run fuzz` and `benches/*.bench.ts` by name.

## How to add

- **A verb:** in its member, through the member's index, recorded by `bun run record` (`tests/api.json`, `tests/size.json`), named in `tests/<member>.test.ts`, fuzzed when it parses, benched when hot, consumed by the surfaces in one line.
- **A member:** `src/<name>/{package.json, src/index.ts}`, a `workspace:*` line and an export in the facade, a test file, a bench file, a place in the ladder; ask first which member owns the domain; the count follows need, neither a ceiling nor a goal.
- **A library:** one catalog pin, one door file in its owning member, named re-exports, a license on the allow-list or a named grant.
- **A platform difference:** a port in the member through `adapter`, its web fallback through `adapter.web` in the port's own file, the native adapter in the surface's `src/native`, bound at boot.

## Direction

The engine carries the surfaces completely: stores, hooks, types and tooling depend on it alone, so features stay business pipelines of a few lines and the three surfaces differ only in their adapters and their elements. The spec language stays one system at every depth (`screen → block → feature`) and one interpreter at runtime. Next laws to land: a credential-shaped value refused by the compiler; a port matrix printed by the surface's boot in the lab. Size and start-up are measured from builds and benches, never policed in code.
