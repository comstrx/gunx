# engine/python

A uv workspace of 49 domain distributions under one namespace, `engine`, and a facade distribution of the same name that owns the namespace root. Sanic is its center; native cores (C, C++, Rust) carry the lifecycle wherever a measurement proves them; ideas are born here before Rust reverse-engineers them.

## Layout

```
engine/python/
├── pyproject.toml        the workspace root `engine-workspace` (members = ["src/*"], depends on `engine`): the one version, every pin in [tool.uv] constraint-dependencies, ruff ALL with scoped per-file ignores, mypy strict, pytest
├── uv.lock  .venv/       the one lock and the one artifact of the workspace
├── src/engine/           the facade distribution `engine`: pyproject.toml (depends on every engine-<domain>) and src/engine/__init__.py: `__path__ = extend_path(...)`, then every domain imported as an attribute
├── src/<domain>/         one member: pyproject.toml (engine-<domain>: the domains and libraries it imports, by name; version dynamic from the root)
│   └── src/engine/<domain>/  the package: __init__.py facade with a sorted __all__ and a lowercase singleton, flat files, py.typed
├── tests/                one test_<domain>.py per member on engine.test against real PostgreSQL, SQLite, Redis and RabbitMQ, and aiohttp wire fakes for every remote provider; conftest.py the shared `provider` fake (a generic HTTP provider that answers what the test queues); test_laws.py the laws; test_api.py every `__all__`
├── benches/              one bench_<domain>.py per member on engine.test.Bench
└── fuzz/                 one fuzz_<domain>.py per member: hypothesis properties over the domain's parsers, verbs and models, run as scripts, silent unless a property fails
```

Every member ships its code under its own `src/engine/<domain>/` because Python needs the import root, `engine`, inside each distribution; a member's `engine/` has no `__init__.py` (a PEP 420 portion), so `engine.http` installs and imports alone and loads only its DAG; the facade's `engine/__init__.py` extends `__path__` over every portion, so `import engine` gives every domain. `griffe` reads the portions without the facade, so the surface check sees every domain merged.

## Laws

- **Final wrapper:** handlers return `http.Answer`, built only by `http.Response`; the one declared raw surface is `database.Session.raw()`, the driver's own connection, for a driver verb the engine lacks. A product proves it by lint: ruff `banned-api` refuses every wrapped library above the engine.
- **Workspace** (test): the facade depends on exactly every member; a member is `engine-<dir>`, ships `engine/<dir>/`, reads its version from the root (`dynamic`), and declares exactly the domains and libraries it imports, by name only; every pin lives once in the root's `constraint-dependencies`.
- **Package** (test): a member is `__init__.py` (the facade: imports and `__all__`, defines nothing), `arch.py` (its constants, patterns, dataclasses and helpers) and one class per other file, named as the file's stem; no loose function outside `arch`; no file beside `.py` but `py.typed`.
- **Proof** (test, gate): every member carries its test file, its bench and its fuzz target, named after it; a verb enters with its test, a hot verb with its bench line, a parser or a model with a property. A defect a fuzz run or a mutation run finds is closed in the source and pinned by a test line, never by loosening the property.
- **Shape** (test): domains form a DAG with `error` as the floor and declare what they import; a facade exports a sorted `__all__` of engine or stdlib names; every header breathes; no comment, print or eval in a source. A file holds one class and takes that class's name; a domain grows by files, never by a second class in one (`http` is `app route group router binder request response outgoing envelope edge throttle channel form action docs` over `arch`; `database` is its door, five drivers with their dialects, `lane session table column index model repository memory documents migrator outbox listener vector cluster plan sql` over `arch`).
- **Ladder** (test): a member leans only on members at or below its rung: `error context log` · `rand func thread adapter exception` · `json parse number date string array` · `crypto token validate config translate metric health cli` · `fs net cache stream storage view` · `database search` · `broker queue event schedule socket broadcast` · `http auth` · `mail sms notify gateway geo domain ai rag video` · `fake test`. A member never does another member's work: text is `string` (`rag` splits sentences through `string.sentences`, `array.where` matches through `string.like`), identities and headers are `parse` (`validate` checks `email phone uuid ulid slug ip mac color` by calling `parse`), pictures are `fs` (`fs.picture thumbnail variants`, `fs.images` over Pillow), parallelism is `thread`; hashing is `crypto` (`ai` keys its embeddings and `auth` its OTP ledger by `crypto.digest`, `cache` loads a script by `crypto.hash(script, "sha1")`), randomness is `rand` (`adapter` and `ai` draw receipt and call ids by `rand.hex`), encodings and globs are `string` (`string.base64` for `ai mail token crypto`, `string.glob` for `auth` scopes, `event` names, `broker` topics and `fs` paths, `string.width` and `string.ratio` for `cli`, `string.digits` and `string.normalize` for `crypto`), URLs and percent-coding are `parse` (`parse.url` reads the Redis, PostgreSQL and MySQL addresses with their passwords, `parse.quote unquote encode` serve `http` and `crypto`, `parse.ip cidr` the trusted proxies). The stdlib a member keeps is the one its own concern is made of (`csv` in a download, `socket` in a port probe, `fnmatch` behind `string.glob`), never a sibling's verb written again.
- **Breadth** (test): `tests/test_breadth.py` maps every verb of Laravel 12's `Str`, `Stringable`, `Arr`, `Collection`, `Number`, the validation rule list, the HTTP client, `Storage`, `Cache`, the scheduler, the queue and the event bus, and every public verb of the Turbox `core/utils` stdlib (string, iters, cast, date, func, fs, parallel, api, config) to its home in the engine: an engine verb, a Python builtin where Python already says it in one word, or a reasoned skip (markdown and css belong to `view`, `exists`/`unique` to `database`, upload rules to `fs` and `storage`, dns to `net`). 969 names, 41 skips, zero unresolved; the test fails the day a renamed verb breaks a mapping. `tests/test_parity.py` goes past names: Laravel's own documented examples for `Str`, `Arr`, `Collection`, `Number` and the validator run through the engine's verbs and must give Laravel's answers (`apa("Creating A Project") == "Creating a Project"`, `excerpt("This is my name", "my", 3, "...") == "...is my na..."`, `pluck(rows, "developer.name")`, `compact(489939, 0) == "490K"`, `pairs(25, 10)`, `spell_ordinal(21) == "twenty-first"`, …); where the engine deliberately differs the test states the engine's answer (`truncate` bounds the whole string, ellipsis included; `mask` keeps both ends; `bytes` speaks IEC; `spell` is American). The engine keeps verbs neither has (`string.arabic eastern sentences read_time highlight ratio distance closest rank direction simplify`, `date` in Egyptian Arabic, `number.spell` in two scripts).
- **Door** (test): a third-party library enters through exactly one domain, at any indentation (`msgspec` → `validate`, `orjson` → `json`, `redis hiredis` → `cache`, `aiohttp yarl` → `net`, `sanic` → `http`, `asyncpg apsw asyncmy clickhouse-connect pymongo` → `database`, `aiormq aiokafka` → `broker`, `av` → `video`, `pillow watchfiles caio` → `fs`, `ray` → `thread` …); every other domain reaches it through that domain's verbs (`cache.Channel`, `validate.Member`, `validator.components`, the stage client over `net`). A library whose import costs tens of milliseconds (`av`, `asyncmy`, `clickhouse_connect`, `pymongo`, `aiokafka`) is imported inside the verb that needs it, never at module top, so a hello service boots without it.
- **No engine table** (test by use): no domain names, creates or owns a table. `database` is one door over postgres (asyncpg), sqlite (apsw), mysql (asyncmy), clickhouse (clickhouse-connect) and mongo documents (pymongo); `Database.connect(url)` picks the driver from the scheme, `Sql` renders per `Dialect` (idents, placeholders, DDL, alters, upsert, JSON paths, vector distance) and refuses what a dialect cannot do (`sql.capability`); a service declares every table and hands it over: `Migrator(db, tables, ledger=Migrator.ledger(name))`, `Outbox(db, table=Outbox.blueprint(name))`, `Events.durable(outbox, db, inbox=Events.blueprint(name))`, `DatabaseStore(db, Rag.blueprint(name, dims))`, `DatabaseEngine(db, Search.blueprint(name, dialect))`. Ids are client-side uuid7 (`Repository Memory Documents`), a dialect without `RETURNING` re-reads by key, and `Repository Memory Documents` answer every verb alike.
- **One error, one typing:** `Fault(code, reason, message, errors, headers)` over a closed set of 26 codes (`status`, `message` and `Code.of` are table lookups), mapped once by `exception` (`map(kind, code | factory)` by the nearest class, `ignore`, `level`, `report`, `context`, `throttle`; reported once; an error nobody mapped is `INTERNAL`, never a client code); `JsonValue` in `json`, `Decimal` money in `number`, `DateTime TimeDelta UTC` in `date`; CPU work through `thread.offload`.
- **HTTP** (test): `http` is the one lifecycle a service boots through, over `socket exception error log` and never under them. `app` holds `App` and its chainable DSL (`App(name, version, limits, origins, docs, headers).throttles(**policies).middleware(*layers).routing(*routes, live, ready).render(kind, renderer).public(folder).lifecycle(*factories)`, `probes`, `mount`, `seal`, `serve`, `describe`); `route` holds `Route` (`get post put patch delete any resource`, `guarded through throttled tagged hide`), `group` the prefix and shared layers, `router` the match and `url` (params percent-encoded), `binder` the signature reader; `arch` holds the shapes `Guard Next Middleware Handler Lifecycle Renderer Mountable Answer Limits`; `edge` holds trace, preflight and stamp, `throttle` the parsed policy (`ip|actor` over a window), one onion per route composed at seal, global layers outside route layers; `channel` holds `Channel.define(path, sockets)`; `outgoing` the response with its fixed headers encoded once, `envelope` the one answer shape; a request layer is `Form` (a `Shape` with `rules`, `reason`, `prepare`, `carries`) bound to an action by `Form.to(call)`, an `Action` that validates the merged path, query and body before the action runs and documents its body or its query; `docs` derives each operation's answers from its route (`2XX`, 401 and 403 when guarded, 404 with path params, 415 and 422 with a body, 429 throttled, `default`). The message is the reason's translation, else the given message, else the code's (`translate` sections `reasons` and `codes`, flat keys; `translate.load(*folders)` merges `<locale>.json` additively; a request's locale is one the catalogs offer); a 5xx shows only the code's. The engine names no folder: a service passes its own paths.
- **Boundary:** every value object and every setting is validated where it is built, never where it is used: a dataclass refuses in `__post_init__` with `<domain>.<thing>` (`mail.message`, `gateway.charge`, `domain.record`, `notify.notice`) and `errors={field: ["is invalid"]}`; a `setup`, a constructor or a wire refuses with `<domain>.settings` and `errors={"setting": [name]}` (`adapter.need` names what is `missing`); `isinstance` before every narrowing (a `bool` is not an `int`, a `str` is not a sequence of them); ttl, sizes, counts and waits are bounded in `arch` constants. A provider's wire is hidden behind `adapter.upstream` (its 4xx become `<family>.provider` as `BAD_GATEWAY`, a malformed body `<family>.reply`, a 5xx stays `remote.<status>` as `UNAVAILABLE`) and `adapter.receipt`; a product never sees a provider's own status text.
- **Security:** input decoded once at the boundary (`validate` shapes and the rulebook), unknown fields refused and named; a shape's `fill` changes only its `fillable` fields (`validate.guarded`) and `dump` leaves out its `hidden` ones; a path part spliced into a URL only through `net.segment` (encoded whole, `. ..` refused); SSRF-safe egress through `net.Egress` (public addresses only unless declared; the resolver pins the address it checked, so the address dialed is the address checked and a name with one inside answer is refused whole; a redirect is checked like a first request, never carries `Authorization`, `Cookie`, `X-Api-Key` or `Proxy-Authorization` across an origin, and rewrites its method like a browser; `Remote` credentials and page cursors stay on their origin); a lock (`cache.lock`, `schedule`) is freed or renewed only by its owner's token, so a late owner never frees its successor; an OTP opens once under a crowd (digested keys, one compare-and-drop of the stored code, a cooldown drawn before the code) and its tries are counted per subject without a subject poisoning another's key; a RabbitMQ consumer resumes after its channel or its connection dies and never trusts a delivery's headers; a pool waiter that is cancelled hands its connection on and a dead connection frees its slot; argon2id passwords; JWT pairs with fingerprints; identity crosses from an edge to a service only through `auth.relay` (an HMAC over actor, roles, scopes, tenant and request id, read by `relay.guard(scope)`, `relay.signature` on a forged header or one carried to another request id); AES-GCM sealing with key ids and `rotate`; `env.load(root)` reads `.env.<ENGINE_ENV or local>` then `.env`, never over a real variable; production never runs on a lab default (under `ENGINE_ENV=production` a string setting with a default whose name marks a secret or an address, `secret password token key dsn url`, must come from the environment, or `Settings.load` raises `config.env` naming every key); tenant isolation by RLS (`Table(isolated=…)` forces row security, `transaction(**scope)` binds `app.<name>` per transaction, the runtime role is `NOSUPERUSER NOBYPASSRLS`, checked by `Provision`); a list is ordered only by a column its model declares `sortable` (`database.order` otherwise).
- **Layer kit:** the generic bases a service's lifecycle layer subclasses: `database.Model` and `database.Repository` (PostgreSQL), `database.Memory` (the same verbs in memory, `make` and `snapshot` beside them, proven answer for answer against the real repository), `validate.Resource` (`fields` or `dump`, `one`, `many`), `http.Form` (strings trimmed by its default `prepare`) and `http.Action`, `http.Layer` (a class with `handle(request, call)` behind the `http.Middleware` callable), `event.Signal` (a typed event: a `Shape` with a class `name`, `dispatch(bus, actor, tenant)` through `events`), `queue.Work` (a typed job: `dispatch(delay, unique, bus)` through `queue`), `Repository.run()` and `Memory.run()` (a `health` probe named after the table while the lifecycle runs; `Repository.ready` pings the database, `Memory.ready` wants a row), `Repository.database` for a service's transactions, `Group.of(prefix, *routes, name)` tagged by its name; it names no folder and imposes no layer, and a product's cycle layer is one line over each of these.
- **Adapters:** every provider is an `adapter.Adapter` with `family`, `name` and declared capabilities under one `Manager` per family; HTTP providers subclass `net.Remote` with one status mapping; `gateway` normalizes charge, refund and webhook; each family ships a log, memory or mock provider for tests (`geo.memory`, `LogMailer`, `MockModel` …).
- **Outbox and recovery:** `queue.durable(outbox)` and `events.durable(outbox)` write the side effect in the request's transaction; a job's `unique` key is held in `cache` at push time; dead pooled connections are recycled; a Redis outage raises typed `UNAVAILABLE`; RabbitMQ publishes with confirms; Kafka and Redpanda ride one `KafkaDriver` (a queue is a consumer group, a requeue is a re-publish with `attempts + 1`, no purge).
- **Native:** `func.pick(name, module, native, pure)` takes the native core when its module imports and the pure path otherwise (`ENGINE_NATIVE=auto|native|pure`); the pure path stays the reference test. Today: `caio` reads, `watchfiles` watching, `stringzilla` search, `pyroaring` bitmaps; `orjson`, `msgspec`, `blake3`, `cachebox`, `rapidfuzz`, `obstore`, `apsw`, `av`, `pillow` are native underneath their domains. `cache.RedisStore` speaks RESP over its own asyncio transport with `hiredis` packing and parsing (`cache/resp.py`, one pipelined connection, measured 1.8x redis-py on MGET); `redis-py` stays only for `cache.Channel` and is imported inside it. `database.PostgresDriver` pools plain asyncpg connections in its own `Lane` (LIFO, lazy growth to `max_size`, recycle after fifteen idle minutes, a rollback only when a connection comes back inside a transaction; scopes are `set_config(..., true)` and locks are `xact`, so no session state leaks) instead of asyncpg's proxy pool with its reset round trip: a short query fell from 541 to about 200 µs p50; lane connections are the real asyncpg objects, so the driver keeps one prepared handle per connection and statement (at most 256 a connection, dropped on a stale-plan error, never for a parameterless `execute`, which stays on the simple protocol for migrations). `Response.raw` answers are `Outgoing`, whose fixed security headers are encoded once per process. Every bounded wait on the request path is `thread.Gate`'s shape, never `asyncio.timeout` per call (a libuv timer armed and cancelled, about twenty microseconds, three times a request before): the `App` admission gate, the Redis wire's inflight cap and the lane's waiters carry a deadline and one timer sweeps them; the Redis wire watches its replies the same way, one timer per connection. The request id is `rand.quick(8)` (the process random generator, reseeded after fork), not a `getrandom` syscall.
- **Parallelism:** `thread.run(items, handler, mode, workers, timeout, retries, ordered, on_result, on_error, fail_fast)` is one DSL over `async` tasks, a thread pool, a spawn process pool, an `InterpreterPoolExecutor` and a Ray cluster (`ray` is lazy; no cp315 wheel today, proven against a fake); `thread.compute(fn, *args, mode)` for one CPU job, `thread.race`, `thread.chunks`, `Run.results/errors/raise_first`.
- **Media and storage:** `storage` is one disk DSL over local folders, S3 (obstore) and Google Drive (`storage.drive(net, token, folder)`, Files API v3 over `net.Remote`); `video` is one DSL over a local FFmpeg driver (`video.local(storage)`: HLS renditions and a poster published to a disk) and Cloudflare Stream (`video.cloudflare(net, token, account, customer)`: upload, status, playback manifests, thumbnails, signed tokens); `video.narrate(path, ai)` sends sampled frames as `Message.images`, which every ai provider carries on its wire.
- **Model and retrieval:** `ai` knows no model name: tasks route to adapters (`chat complete embed stream extract run`), tools are `Tool(name, description, parameters, handler)` and `Ai.run(turn, tools)` loops until the model answers, `Ai.extract(messages, Shape)` asks for the shape's JSON schema and validates the answer, embeddings are cached in `cache` by text hash; `rag` scopes chunks by namespace, never by authorization, packs sentences, fuses vector and keyword ranks when a `Search` is wired (`hybrid=True`), cites what it returns and answers from the cited sources only.
- **Search:** `Search` is one door over `MemoryEngine` (BM25), `DatabaseEngine` (tsvector on postgres, term frequency elsewhere), `ElasticEngine`, `MeiliEngine` and `VespaEngine` (REST over `net.Remote`); the engine verb is `prepare(index, Schema)` because `Adapter.ensure` already means a capability; a query names only `searchable`, `filterable` and `sortable` fields, anything else is `search.sort|filter|facet`.
- **Bytes and media:** `stream` owns the wire shapes of a byte stream (`Range` per RFC 9110 with a 416 that carries `Content-Range`, `Served` for 200/206/304 answers with weak ETags, `Pipe` and `Tee` with backpressure, `Hls`/`Dash` playlists, `Uploads` resumable by offset); `video` decodes, probes, transcodes, remuxes and packages HLS through FFmpeg (source timestamps are kept, the demuxer's flush packet is decoded, HLS keyframes are pinned at the segment length); `fs.images` decodes a picture under a pixel budget, strips metadata by repainting, and encodes webp/avif/jpeg/png/gif; both do their work through `thread.offload`.
- **Sockets:** `Sockets.setup(capacity, limit, idle, rate, span, channels, history)`, `authorize(gate)` on `join`, `Hub.history/replay` for late joiners, one error frame per refusal (`socket.rate`, `socket.channels`, `socket.forbidden`).
- **Stage:** `engine.test.stage` wires the engine (`wire`), opens real services (`provision`), builds the reference application with `/health /ready` (`App.probes()`, which every service mounts the same way; the `App` records its service and version on start) and `/metrics` (`application(*routes, origins=…)`), serves it on a free port with a typed client (`client`: `get post put patch delete`, `bearer`, `expect`), and closes every pool (`close`); `Bench.measure` prints p50/p95/p99.

## Gate

`infra gate --part python` (`--type all` adds `bench` and `fuzz`) = `uv sync --locked` · `uv run mypy` · `uv run ruff check` · `uv run pytest -q` · the same suite under `PYTHONDEVMODE=1 PYTHONMALLOC=debug PYTHONWARNINGS=error` (safety) · `uv export --frozen --no-emit-project --no-emit-workspace --no-hashes` minus the path members `| uv run pip-audit -r /dev/stdin --strict` and `griffe check engine` over every member against the newest `v*` tag (audit); `uv run python <file>` per `benches/` and `fuzz/` target by name.

## How to add

- **A verb:** in its domain, a flat file or the file of its concern, exported by the facade, pinned in `tests/test_api.py` and the domain's test file, benched when hot.
- **A domain:** `src/<name>/pyproject.toml`, `src/<name>/src/engine/<name>/{__init__.py, py.typed, …}`, a workspace source in the root, a dependency and an import in the facade, its names in `tests/test_api.py`, `uv lock`, a place in the ladder.
- **A provider:** one `Adapter` subclass behind its family's manager, a log or mock implementation for tests, the real one proven against the service or an aiohttp fake of its exact wire (the fake is written from the provider's documentation and says so).
- **A driver:** one `database.Driver` with its `Dialect` and `translate(error)`; its tests run live when the service is on the box, otherwise they stay honest about it.
- **Seeded data:** `fake` draws people, places, cards, IBANs and phones with valid shapes (mod-97 IBANs, Luhn cards, real EG/SA/AE/QA/JO/OM/KW/BH numbering plans) and reserved documentation values where a standard offers them (`example.*` domains, the TEST-NET addresses); a phone or an email it draws can coincide with a real subscriber, so a live sender is never pointed at seeded data; the lab, the memory providers and the log providers are the only sinks for it.
- **A native core:** one `func.pick` in the domain, the same signature as the pure path, chosen by a measured bench on a stated machine, the pure path kept as the fallback and the reference test.

## Measured

On this box (8 cores, WSL2, 2026-11-09, services co-located), `GET /api/ping` through the full edge, one worker pinned to one core, the load generator pinned away: bare Sanic 5,000–5,800 requests a second at one connection and 8,500–9,000 at sixty-four; the engine 2,600–4,100 and 5,000–6,100 the same minute. The gap is the edge (request id, context, CORS, security headers) plus box jitter; the day before, with the edge mirrored into the hybrid, the two were level at one connection.

The SaaS workload of the hybrid lab (its `schema.sql` and `load.lua`: 32 tenants, 80/20 reads and writes, half the reads forced to miss, orders confirmed in RabbitMQ before the answer, a job pipeline writing notifications), 64 connections, 30 s, four API workers on four cores, same PostgreSQL, Redis and RabbitMQ, run back to back: hybrid 3,754 requests a second (p50 14 ms, its job workers 13,788 events behind at the end); the engine 3,411 (p50 14 ms, 10 events behind), from 1,586 at the start of the round. The steps that paid, each measured alone: the RESP wire (+38%), skipping asyncpg's release reset, leasing a connection without an async context manager (2,725 → 3,343), acquiring without a timeout wrapper while a connection is idle. The steps that did not: a prepared-statement cache keyed by the pool's proxy (every call prepared again, 3,343 → 1,850), coalescing Redis writes behind `call_soon` (one loop hop per command, −15%). An admission limit (`Limits(concurrency=16)`) trades 4% of throughput for a p99 of 86 ms instead of 105. The APIs alone, no job workers, alternating five pairs of 20 s after the last two steps (a lane pool of plain asyncpg connections in place of asyncpg's proxy pool, and the fixed security headers encoded once per process instead of once per response): hybrid 4,564 / 4,049 / 3,971 / 3,980 / 2,994 (mean 3,912), the engine 3,882 / 3,953 / 3,950 / 3,937 / 3,861 (mean 3,917); the engine's p50 is lower in every pair (12.2–12.4 ms against 12.0–20.5) and its spread is a fiftieth of the hybrid's; p99 72–86 ms without admission, 53–55 with `Limits(concurrency=8)` (the hybrid 41–77 under its own admission of eight). Level on throughput with the edge on, ahead on latency and steadiness, ahead on the pipeline. Soaked five minutes at sixty-four connections with the admission limit: 862,392 requests, 2,874 a second, p50 19 ms, p99 99 ms, no error, 172,490 orders every one with its items and its notification, two events in flight at the end (the hybrid's own five-minute record on its lab box is 2,330). The harness lives in the scratchpad and is the next round's bench.

At the close of the grand round (2026-11-11, the same workload and harness, the box shared with other sessions at load 2–4), five alternating pairs of 20 s at sixty-four connections, four API workers on four cores, no job workers: hybrid 2,848 / 2,587 / 2,805 / 3,642 / 3,163 (mean 3,009), the engine 3,599 / 2,810 / 2,715 / 3,304 / 3,913 (mean 3,268); the engine's p50 lower in every pair (13.9–20.1 ms against 16.4–21.5), its CPU a request lower in four of five (812–1,062 µs against 896–1,177), no invalid answer in 561,000 requests. Three of the five engine runs stand above 3,000 requests a second and two fall under it with the hybrid falling the same minute: on this box the number is the box's, the CPU a request is the engine's.

Hello side by side on the quiet box, same minute: bare Sanic 8,400–8,600 at one connection and 12,200 at sixty-four; the engine 5,800 and 8,100. Variants prove where the difference lives: trace and stamp with their five headers cost 16% at sixty-four connections (8.9k → 10.3k without them); the envelope costs nothing measurable. The edge stays on: the comparison standard is equal work.

The ceiling, defined and measured: the floor of this stack is bare Sanic on uvloop answering `raw()` with no edge at all, 111.1 Python calls a request under the profiler at sixty-four connections; bare Sanic carrying the same five security headers, request id and repeated-header check costs 176.2; the engine with its whole edge (request context facts, locale negotiation, bearer parsing, the envelope, the stamp) costs 177.0, level with the equal-work bare app and 1.59× the floor. The last step was the edge itself: `trace` and `stamp` run inside the route wrapper, so an API route carries no Sanic middleware and Sanic skips its runner (two dispatches, two awaitable checks); the exception handler traces a request nobody traced (a 404, a 405, a preflight on a GET-only route) and stamps every error answer; static files, websocket upgrades and `/openapi.json` sit on a blueprint whose middleware is the same two functions (Sanic ignores a bound method there, so they are wrapped in plain functions); `stamp` marks the context so a second pass is a no-op. Everything else that did not change behavior is gone (`Response.ok` builds the `Outgoing` directly, the binder's wrappers return a ready answer without the `answer` hop, the envelope reads the context facts once and hits the word cache without a call, `context.close` resets and hands back pending deferrals in one step, `log.debugging` is a flag, the header check is a module function, the encoder is one comprehension). What remains between 111 and 177 is the edge's semantics, priced at the same cost as writing them by hand. Wall-clock hello numbers on this box swung 40% between identical runs that night and are not quoted.

The night lap (2026-11-09, the box slower than the afternoon: the hybrid itself fell from 3,912 to 2,853 on the same workload) was measured two ways because wall-clock numbers swung 40% between identical runs. First, `cProfile` under the load generator on one worker, counting calls a request, which the host's jitter does not move: 579.5 → 545.9 Python calls a request, the engine's own 90 → 80, `asyncio.timeout` entries 13.9 → 1.1 (what remains is aiormq's own confirm wait). The cuts behind it: the header encoder as one list comprehension with `str.translate` (no sanitizer frames), `trace` and `stamp` reading `request.ctx` once and the authorization header before `token.bearer`, `Envelope.word` keyed on the raw context locale, `Outgoing` without an `__init__` frame, the binder's parameters resolved by closures built at bind time, the admission wrapper calling the handler directly when nothing wraps it, `Database.fetch/execute` calling the driver without a `Session`, `binds` as one comprehension, the lane's prepared handles, the Redis store adding its prefix inline, and the three bounded waits on `Gate`'s deadline-and-sweep shape. Second, CPU microseconds a request read from `/proc` across the server tree, which jitter moves less than throughput: hello with the full edge 137–142 µs at sixty-four connections against bare Sanic carrying the same five headers and request id at 128–139 (147–167 against 162–167 at one connection). The SaaS workload, APIs alone, four workers each, five alternating pairs of 20 s: hybrid 2,625 / 2,787 / 3,117 / 2,608 / 3,127 requests a second (mean 2,853, 1,043 µs CPU a request), the engine 3,017 / 2,949 / 3,176 / 3,109 / 3,519 (mean 3,154, 963 µs): ahead in every pair, a lower p50 in every pair (14.7–17.8 ms against 17.2–23.6), 7.7% less CPU a request, while the hybrid's answers carry no request id and no security headers and the engine's carry the full edge. Soaked 120 s with three job workers: 246,583 requests, 2,055 a second, p50 26 / p99 127 ms, no error, 49,325 orders each with its three items and its notification, one outbox row in flight eight seconds after the end, no traceback in any process. Two more alternating series after the last cuts, the second gated on an idle box (load under 2, no foreign process above 40% before every run): hybrid 2,896 / 2,457 / 3,054 / 2,508 / 2,899 against the engine 2,613 / 3,245 / 2,733 / 2,924 / 3,064 (means 2,763 against 2,916, CPU 1,136 against 1,063 µs a request); then hybrid 2,394 / 2,702 / 3,300 / 3,270 / 2,641 against the engine 3,135 / 3,188 / 3,308 / 1,863 / 2,661, the fourth engine sample landing on a load spike to 4 (means 2,862 against 2,831 with it, 2,759 against 3,073 without). Across the fifteen pairs run since the gate and watchdog landed the engine answered more requests in twelve, with the lower p50 in fourteen and less CPU a request in twelve; a sixty-second series run while another session's `hermesc` build held a core at 90% went the other way and is not counted. On this shared box the stable claim is the paired one: same minute, same services, the engine with its full edge does the hybrid's bare work for less CPU a request and answers it sooner. A duel with both servers resident and ten alternating 10 s bursts (order swapped every round) ran with the load climbing from 4 to 12 on eight cores and went the other way: hybrid 201,230 requests to the engine's 191,290 (−4.9%), CPU a request level (1,424 against 1,416 µs), seven rounds to three, the engine's p99 worse in most rounds and one burst with 124 admission refusals and a 934 ms p99. Under contention the engine's tail is the weak point, not its mean cost; the first suspect is the cyclic collector (the hybrid freezes its heap after boot, the engine does not yet), to be measured with the harness's `SAAS_GC` toggle before anything is changed. The harness (`saas/series.sh`, `ab.sh`, `soak.sh`, `queues.py`) lives in the scratchpad; both apps share Redis db 13, so volatile keys are cleared before every run (the hybrid writes plain JSON under the same catalog key the engine stores as bytes).

## Direction

Widen the margin on a quiet box: Sanic's middleware runner replaced by the edge inside the route wrapper, header names encoded once, `Record` rows without a dict copy where the contract allows, the Redis wire writing once per loop turn if a measurement ever shows the syscall dominating. Then Laravel's breadth and ease with the best measured latency in Python: every lifecycle domain several times stronger (database, cache, queue, schedule, event, socket, http), every domain a DSL, adapters for every provider family, configuration folded into settings groups, boot and warm-up as a discipline, the command line as the manual. The database dream: one declarative file per table, a diffing migrator that plans typed operations with a safety class, expand first, backfill in resumable batches, contract in a separate run, proven on millions of rows. Live proof for mysql, clickhouse, mongo, kafka, elasticsearch, meilisearch and vespa the day those services stand on a box. Everything proven here is the Rust engine's next lap.
