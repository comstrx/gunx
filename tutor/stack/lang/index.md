# Languages

## Contract

Select language practice independently of business and implementation-library policy.

## Structure

Each child owns naming, hand style, language semantics, resource behavior and native proof techniques.

## Rules

Language lessons are terminal knowledge: return to the caller rather than routing upward recursively.
Latest stable is verified before relying on new syntax. Installed toolchain compatibility must be demonstrated before a pin changes.

## Proof

Selected language matches the implementation; no missing language prerequisite and no redundant reread within the pass.

## Sources

Each child links official language documentation.
