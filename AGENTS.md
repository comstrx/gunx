# Agents

This repository is governed by `tutor/`. Read `tutor/index.md` first and follow its reading order before you touch a file. The files under `tutor/` are the operating contract for every AI agent and every engineer who works here: the vision, the stack, the way of working, the shared reference, and one file per engine and per product part with its laws, hand style and direction.
They outrank default habits, tool conventions and prior assumptions. The code is the truth about the current state; `tutor/` is the truth about how the code must be written, verified and shipped. Nothing outside the two is a source of truth.
